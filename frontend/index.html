FAQ

Questions, answered.

What happens when a link expires?

The link stops working right away and the file is deleted from storage within 15 minutes. A storage rule also removes anything older than a day, so nothing is ever kept by accident.

Does the person I send it to need an account?

No. They open the link, enter the password if you set one, and download. Only you need an account to upload.

How big can my files be?

Up to 2 GB per file and 10 GB of live files at once. Files go straight from your browser to Amazon S3, so big files upload as fast as your connection allows.

Can I change a link after sharing it?

Yes. You can rename the file, extend the timer (up to 24 hours after upload), add or remove the password, change the download limit, edit the note, or delete it immediately.

Is this a real product?

It's a working portfolio project that shows cloud architecture and DevOps on AWS: load-balanced Docker containers, serverless functions, infrastructure as code and automated deploys. Everything on this page works.
